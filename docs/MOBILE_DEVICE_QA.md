## iPhone／iPad（Safari）

- [ ] 以 Safari 開啟 `/offline/character/ui/index.html`。
- [ ] 等待畫面顯示「離線快取已完成」。
- [ ] 使用「分享」→「加入主畫面」安裝。
- [ ] 確認主畫面名稱與圖示正確。
- [ ] 從主畫面啟動，確認以獨立視窗開啟。
- [ ] 確認瀏海／動態島、底部手勢區沒有遮住按鈕或文字。
- [ ] 直向與橫向旋轉，確認地圖、方向控制與主要功能可用。
- [ ] 建立角色、移動、戰鬥、使用藥水、裝備道具及學習技能。
- [ ] 關閉 App 後從主畫面重新開啟，確認角色與所有狀態仍存在。
- [ ] 首次快取完成後開啟飛航模式，強制關閉再啟動，確認角色管理與遊戲都能載入。
- [ ] 匯出 JSON 備份，確認可在「檔案」App 找到；另以測試資料驗證匯入與覆蓋確認流程。

## Android（Chrome）

- [ ] 以 Chrome 開啟 `/offline/character/ui/index.html`。
- [ ] 等待畫面顯示「離線快取已完成」。
- [ ] 從 Chrome 選單選擇「安裝應用程式」或「加到主畫面」。
- [ ] 確認名稱、圖示正確，並能以獨立視窗啟動。
- [ ] 確認系統狀態列、導覽列與螢幕挖孔區不會遮住操作。
- [ ] 直向與橫向旋轉，確認地圖、方向控制與主要功能可用。
- [ ] 建立角色、移動、戰鬥、使用藥水、裝備道具及學習技能。
- [ ] 強制停止並重新啟動 App，確認 IndexedDB 存檔仍存在。
- [ ] 首次快取完成後關閉網路，重新啟動 App，確認離線載入。
- [ ] 匯出 JSON 至下載資料夾，並以測試資料驗證匯入與覆蓋確認流程。

## 長時間操作與裝置穩定性

每台裝置至少連續操作 30 分鐘，記錄以下項目：

- [ ] 持續觸控移動至少 10 分鐘，沒有方向按鈕卡住或無回應。
- [ ] 反覆進行戰鬥、技能施放、背包及裝備操作。
- [ ] 每 5 分鐘切到背景再返回，確認畫面與存檔狀態正確。
- [ ] 重新整理或關閉重開後，角色位置、HP／MP、經驗、背包、裝備及技能資料一致。
- [ ] 沒有白畫面、非預期重新載入、無法操作或資料遺失。
- [ ] 記錄明顯卡頓、發熱、耗電、記憶體回收或瀏覽器關閉情況。
- [ ] 測試過程中匯出一份備份，確認檔案可讀且大小合理。
