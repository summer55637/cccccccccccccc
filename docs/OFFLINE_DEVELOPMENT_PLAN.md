# 單機版開發路線圖

## 固定開發邊界

- 主要工作分支：offline/local-character-system。
- main 不得修改，除非使用者另外明確授權。
- 原始備份分支必須保持 Private，不部署、不公開分享。
- 不修改既有 Cocos 成品、server.js 或原始資源包。
- 現有客戶端及素材的授權範圍尚須正式確認；未確認前只使用獨立程式碼及自製介面。
- 單機程式不應依賴舊帳號、Token 或原遊戲伺服器。

## 完成項目

1. 架構與資料夾：建立 offline 目錄及開發說明。
2. IndexedDB：角色、背包、裝備、技能、任務及設定資料表；角色建立、讀取、更新、刪除及存檔。
3. 角色管理畫面：建立、列表、選擇、編輯及刪除角色；重新載入後恢復最後選擇。
4. 存檔備份：JSON 匯出、版本與欄位驗證、覆蓋前確認、原子性匯入。
5. 角色能力值及升級核心：四種職業的自製原型初始能力值、經驗值曲線、Lv.99 上限、升級 HP／MP 成長、能力點數及分配介面。
6. GitHub Actions：Chromium 真瀏覽器自動測試，涵蓋 IndexedDB、角色介面、備份／還原及角色成長。

## 接下來的開發順序

### 第 1 階段：角色核心（目前進行中）

- [x] 職業初始能力值。
- [x] 經驗值及升級規則。
- [x] HP／MP 隨職業升級成長。
- [x] 升級後取得能力點數。
- [x] STR、DEX、INT、AGI、VIT、LUK 點數分配。
- [x] 角色資料保存至 IndexedDB。
- [ ] GitHub Actions 最新一輪測試通過確認。

### 第 2 階段：遊戲主畫面

- 角色狀態列、HP／MP、經驗值及能力摘要。
- 主遊戲視窗及功能區入口。
- 從角色選擇畫面進入遊戲主畫面。
- 以獨立自製 UI 及示意場景開始，不重用未確認授權的素材。

### 第 3 階段：地圖與移動

- 自製測試地圖、角色座標及方向移動。
- 鍵盤／觸控操作。
- 地圖邊界與障礙碰撞。
- 地圖資料及角色位置保存。

### 第 4 階段：怪物與戰鬥

- 自製測試怪物及 AI 狀態。
- 普通攻擊、命中、傷害、冷卻與死亡。
- 戰鬥結果提供經驗值及道具獎勵。
- 戰鬥流程測試。

### 第 5 階段：背包與道具

- 道具資料模型、堆疊及容量限制。
- 道具拾取、使用、丟棄。
- 武器與防具裝備欄。
- 背包及裝備存檔測試。

### 第 6 階段：技能

- 職業技能資料、學習條件及技能等級。
- MP 消耗、冷卻及施放效果。
- 技能快捷欄及保存。
- 技能與戰鬥整合測試。

### 第 7 階段：整合、檢查及發布準備

- 連結角色、地圖、戰鬥、背包及技能狀態。
- 斷線／重新整理／重開後存檔恢復測試。
- 效能與錯誤處理。
- 公開發布前重新確認程式、素材及品牌授權。
- 完成憑證輪替、Git 歷史敏感資料處理及部署內容掃描。
- 確認不會把備份、私密資料或受限制素材放進公開部署。

## 規則與授權說明

目前角色能力值、經驗曲線、升級點數及職業 HP／MP 成長是本專案自行設計的原型數值，不代表任何官方或私人伺服器的精確公式。若要精確對齊某一版本，須先取得可使用的規則來源及適用授權，再以設定表調整。

## 發布限制

目前倉庫保持 Private。完成單機原型不等於取得原遊戲客戶端、圖像、音樂、字型或品牌素材的再發布權利；在授權及安全檢查完成前，不開啟 GitHub Pages 公開部署。
