# 單機版開發路線圖

## 固定開發邊界

- 主要工作分支：offline/local-character-system。
- main 不得修改，除非使用者另外明確授權。
- 原始備份分支必須保持 Private，不部署、不公開分享。
- 不修改既有 Cocos 成品、server.js 或原始資源包。
- 現有客戶端及素材的授權範圍尚須正式確認；未確認前只使用獨立程式碼及自製介面。
- 單機程式不應依賴舊帳號、Token 或原遊戲伺服器。

## 完成項目

1. IndexedDB 角色資料庫及 CRUD。
2. 角色管理畫面：建立、列表、選擇、編輯及刪除角色。
3. 存檔備份：JSON 匯出、版本與欄位驗證、覆蓋前確認、原子性匯入。
4. 角色能力值及升級核心：四種職業的自製原型初始能力值、經驗曲線、Lv.99 上限、升級 HP／MP 成長、能力點數及分配介面。
5. 遊戲主畫面：角色狀態、HP／MP、經驗及能力摘要。
6. 本機地圖與移動：20×12 新手村、鍵盤／觸控移動、障礙與邊界碰撞、位置自動保存。
7. GitHub Actions：Chromium 真瀏覽器測試涵蓋資料庫、角色介面、成長、地圖移動及備份。
8. 怪物與基本戰鬥：自製怪物出生點、AI 狀態、普通攻擊、傷害、反擊、冷卻、經驗獎勵、掉落及重生保存。
9. 背包與道具：道具堆疊、藥水使用、丟棄、武器防具裝卸及裝備戰鬥加成。

## 規則與授權說明

目前角色能力值、經驗曲線、升級點數、職業 HP／MP 成長及新手村地圖都是本專案自行設計的原型，不代表任何特定天堂伺服器的精確規則。若要精確對齊某一版本，須先取得可使用的規則來源及適用授權。

## 發布限制

目前倉庫保持 Private。完成單機原型不等於取得原遊戲客戶端、圖像、音樂、字型或品牌素材的再發布權利；在授權及安全檢查完成前，不開啟 GitHub Pages 公開部署。
