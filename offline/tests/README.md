# 單機系統測試

## IndexedDB 角色資料庫測試

開啟 `indexeddb-test.html` 並按「執行完整測試」。測試使用一次性的臨時資料庫，完成後自動刪除。

目前測試項目：

- 建立 IndexedDB 及資料表。
- 建立角色並初始化背包、裝備、技能及任務資料。
- 依角色 ID 讀取角色。
- 阻止重複角色名稱。
- 阻止修改角色識別碼。
- 更新角色等級、經驗、能力值及座標。
- 保存及讀取背包、裝備、技能及任務。
- 列出角色。
- 關閉資料庫後重新開啟，確認存檔持續存在。
- 刪除角色及其附屬資料。

## 後續待補測試

- 非法名稱、數值及存檔格式。
- 瀏覽器儲存空間不足。
- 資料庫升級及多分頁阻擋。
- 存檔匯出／匯入。
- 地圖、戰鬥及背包資料一致性。
- 斷網時必要資源快取。

測試只使用自建假資料，不使用真實帳號或憑證，也不連線原遊戲伺服器。
