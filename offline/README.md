# 單機版開發區

此資料夾是獨立的單機版開發區，與目前的線上版建置成品分開。

## 目標

- 不使用原遊戲帳號、密碼或登入 Token。
- 角色資料由玩家自己的瀏覽器保存。
- 逐步建立角色選擇、角色存檔、地圖、戰鬥及背包系統。
- 使用 Service Worker 預快取自製遊戲入口、介面與執行模組；首次連線完成快取後，可在斷網時開啟角色管理及遊戲。

## 安全與授權界線

- 不修改 `main`。
- 不修改既有 `client/`、`server.js` 或任何既有資源包。
- 不複製、解包、反混淆或重新發布目前的遊戲程式及素材。
- 只有在授權明確涵蓋修改、使用及公開發布時，才可規劃整合相應資產。
- 不在此目錄保存密碼、Token、金鑰、Cookie 或其他機密。
- 不把原始備份或含有歷史敏感資料的分支部署到公開網站。

## 目錄

- `character/`：角色資料模型、管理服務與介面。
- `storage/`：IndexedDB 存檔及備份。
- `game/`：地圖、戰鬥、背包等單機遊戲邏輯。
- `integration/`：日後與已獲授權的遊戲前端整合。
- `tests/`：資料、存檔、離線邊界及斷網啟動測試。
- `service-worker.js`：單機版資源預快取與斷網回應。

## 離線使用方式

1. 先在支援 Service Worker 的安全來源開啟角色管理頁（HTTPS 或 localhost）。
2. 首次連線時，瀏覽器會安裝 Service Worker 並快取自製遊戲的 21 個必要資源。
3. 快取完成後，即使斷網，也可重新整理遊戲、返回角色管理頁，並繼續使用該瀏覽器中的 IndexedDB 存檔。
4. 瀏覽器清除網站資料會一併刪除本機角色存檔及快取；重要角色請定期匯出 JSON 備份。

修改快取資源清單或更新正式程式時，必須同步提高 `service-worker.js` 的 `CACHE_NAME` 版本，讓瀏覽器重新安裝完整快取。

目前是可操作的自製單機原型，尚未整合或使用現有 Cocos 成品。倉庫仍為 Private，尚未啟用公開部署。
