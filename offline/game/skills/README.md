# 職業技能

此模組使用本專案自行設計的技能資料與公式，完全在瀏覽器本機執行。

## 職業技能

- 騎士：強力斬擊、破盾重擊。
- 精靈：疾風箭、連環箭。
- 法師：火焰箭、冰霜長矛。
- 領主：王者斬、號令衝擊。

每個職業有一項 Lv.1 可學技能，以及一項需角色 Lv.3 且前置技能 Lv.2 的進階技能。每項技能最高 Lv.3，提升技能會提高傷害倍率。

## 技能點數

- 新角色有 1 點起始技能點。
- 角色每升 1 級取得 1 點技能點；一次跨多級會按實際升級次數發放。
- 學習或提升技能消耗 1 點。
- 技能點數、已學技能、快捷欄與冷卻時間均保存至 IndexedDB。
- 舊角色及舊版備份若沒有技能點欄位，讀取時會補 1 點；原有已學技能不會被清除。

## 施放規則

- 各技能有獨立 MP 消耗、冷卻時間、命中率及射程。
- 騎士／領主主要是近身攻擊；精靈／法師具有遠距攻擊。
- MP 不足、技能冷卻中、角色死亡、目標不存在、怪物已死亡或距離超出技能射程時，拒絕施放且不扣 MP。
- 成功發動後消耗 MP 並啟動冷卻；即使命中落空，仍會扣除施放成本。
- 命中傷害以主屬性、角色等級、技能倍率、技能等級和武器攻擊加成計算，再扣除目標防禦；命中最低傷害 1，落空傷害 0。
- 怪物未被擊敗時仍可能反擊；擊敗後取得經驗並依既有規則取得掉落物。
- 技能冷卻時間戳記會持續保存，重新載入後不會重置。

## 快捷欄與備份

提供 4 格技能快捷欄，只能放入目前職業已學習的技能。快捷欄按鈕會依 MP 和冷卻狀態停用。

JSON 備份／還原包含技能點數、已學技能、快捷欄及冷卻。舊版僅含 learned 的技能存檔與備份仍可讀取。

## API 與測試

- `getSkillBook(database, characterId)`
- `learnSkill(database, characterId, skillId)`
- `assignSkillShortcut(database, characterId, skillId, slot)`
- `castSkill(database, characterId, skillId, spawnId, options)`
- `offline/tests/skills-test.html`：13 項技能服務與 IndexedDB 測試。
- `offline/tests/character-ui.test.mjs`：實際操作技能學習、提升、快捷欄施放及 MP／獎勵保存。
- 備份 UI 測試會確認技能欄位匯出及還原。

所有技能名稱、數值及傷害公式均為本專案自製原型，不代表任何既有遊戲版本或伺服器設定。
