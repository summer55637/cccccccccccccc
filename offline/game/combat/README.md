# 本機戰鬥

使用本專案自行設計的怪物資料與戰鬥公式，完全在瀏覽器端運作，不連線舊遊戲伺服器，也不讀取原始遊戲素材。

## 怪物與 AI 狀態

- 森林史萊姆：Lv.1、HP 28、攻擊 3、防禦 1、18 EXP，掉落透明凝膠。
- 苔原幼獸：Lv.2、HP 46、攻擊 5、防禦 2、36 EXP，掉落粗糙獸皮。
- 新手村目前有三個固定出生點；怪物不會穿越障礙。
- 怪物依玩家距離進入待機、警戒或攻擊狀態；相鄰時可反擊。此階段是固定位置的原型 AI，尚未加入自主巡邏及追逐移動。

## 普通攻擊規則

- 只能攻擊上下左右相鄰一格的怪物。
- 普通攻擊冷卻 700 毫秒；玩家命中率原型值 90%。
- 玩家攻擊力以 STR、角色等級及 DEX 計算，再扣除怪物防禦，最低傷害為 1。
- 怪物反擊依自身命中率、攻擊力及玩家 VIT 計算。
- HP 歸零時角色無法繼續發動攻擊；目前尚未加入復活流程。

## 獎勵與保存

- 擊敗怪物會取得其經驗值。
- 掉落物會自動加入背包；若背包沒有空位，該次掉落不會加入。
- 怪物死亡狀態、最後攻擊時間及重生時間保存於 IndexedDB 設定資料。
- 史萊姆 20 秒、幼獸 30 秒後重生；重新載入頁面仍保留死亡倒數。

## 介面與測試

遊戲主畫面顯示怪物位置、HP、距離與 AI 狀態；接近怪物後可按「普通攻擊」。戰鬥測試頁為 `offline/tests/combat-test.html`，由 Chromium CI 自動執行。

所有怪物、數值及公式都是本專案原創原型，不代表任何既有遊戲伺服器的正式設定。
