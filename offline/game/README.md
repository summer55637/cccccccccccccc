# 單機遊戲邏輯

此處放置獨立於原線上服務、可在瀏覽器本機執行與保存的遊戲邏輯。

## 模組

- `world/`：新手村地圖、座標、鍵盤／觸控移動與碰撞。
- `combat/`：自製怪物、待機／警戒／攻擊 AI、普通攻擊、反擊、傷害、冷卻、EXP、掉落及重生。
- `inventory/`：道具資料、堆疊、藥水使用、丟棄、武器防具裝卸。
- `skills/`：四職業技能、技能點、學習／升級條件、MP、獨立冷卻、傷害及四格快捷欄。
- `progression/`：角色職業初始能力、EXP、升級、HP／MP 成長與能力點分配。

## 整合方式

`main.js` 組合遊戲畫面、地圖、戰鬥、背包及技能系統；所有角色、裝備、背包、技能欄與快捷欄均由 IndexedDB 本機資料管理。技能施放會沿用既有怪物戰鬥流程，擊敗目標後使用相同 EXP 與掉落規則。

遊戲規則、技能資料、地圖及介面皆為本專案自製原型，不使用原伺服器 API、WebSocket、線上帳號或原始 Cocos 素材。
