# 本機角色選擇與建立介面

入口：`offline/character/ui/index.html`

## 功能

- 讀取 IndexedDB 中的角色清單。
- 建立騎士、精靈、法師及領主等測試職業角色。
- 顯示角色等級、職業、HP、MP、最後更新時間。
- 選擇角色並將目前選擇保存至 IndexedDB 的 `settings` 資料表。
- 編輯角色名稱及職業。
- 刪除角色前二次確認，並由資料庫同步刪除附屬存檔。
- 重新整理後恢復角色清單及最後選擇的角色。

## 執行

以 localhost 或 HTTPS 提供倉庫根目錄的靜態檔案，再開啟：

`/offline/character/ui/index.html`

預設資料庫名稱為 `offline-adventure-save`。自動化測試可以透過 `?dbName=...` 指定隔離的測試資料庫名稱。

## 測試

GitHub Actions 會使用 Chromium 實際操作建立、編輯、選擇、重新載入及刪除流程，並確認角色管理頁沒有對外部網站發出請求。UI 測試使用一次性資料庫，結束後自動刪除。

## 注意

「進入冒險」目前只確認角色選擇並顯示狀態；地圖、戰鬥、原 Cocos 客戶端尚未整合。本介面不呼叫原遊戲登入服務、不要求帳號密碼，也不使用原遊戲素材。
